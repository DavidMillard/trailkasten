# 40-Resources — Resource Notes

What `/ingest-resource` produces: one note per source, holding a summary, the concepts
extracted from it, and the original content preserved underneath. Named by source type —
`Article - ...`, `Chapter - ...`, `Conversation - ...`.

This folder is downstream. Raw material you want ingested goes in `80-Fleeting/`; the
command reads it from there and writes the tidied note here.
